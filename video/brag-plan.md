# agent-console — feature tour plan

- **What:** one installable web app that drives Claude Code, Codex and Pi on an always-on machine, from a laptop or a phone.
- **For:** a developer who runs coding agents all day and is not always at the machine doing the work.
- **Sets it apart:** three agents in one thread list; the server keeps working when the device sleeps; agents can stop and ask, you answer with a tap.
- **Angle:** a deadpan technical treatise (style of mexicat/pdoom-video): ink, bone, one signal orange, hairline drafting grid, mono annotations, a spark that draws the connections.
- **Hook (0–3.75 s):** "Claude Code. Codex. Pi." stamped on the beat, hairlines converge into "One console."
- **Highlights:** real desktop UI on a laptop; same work steered from a phone; lid closes and phone sleeps while the turn keeps counting, push notification wakes it; inline question card answered with a tap. Then twelve feature chapters: model and effort pickers, file viewer (code + media), Acode editing, scheduled tasks, GitHub triage, usage and savings, host and context, session search; a recap sheet ties them together.
- **Punchline:** "agent-console — Claude Code, Codex and Pi, from any device." + `bin/agent-console start`.
- **Tone:** pdoom: dry, precise, dynamic; cuts on downbeats, strong eases, holds then snaps.
- **Sound:** original synth track, 128 BPM, A minor, 64 bars (120 s); second half moves to Am Em F G with a lead line; stamps, clock ticks and the notification chime are in key. No voiceover.
- **Data:** every thread, prompt and message on screen comes from a mock scratch instance with fictional content. No real threads, accounts, hosts or usage numbers. Exception: the Acode chapter is a real recording of the owner's Android phone opening a demo file; unrelated Acode tab names are blurred. The notification card is a rebuilt illustration.
