Edit files in Acode

Install or update the bridge. No SSH, SFTP, passwords, or server settings to enter.

Save any open files before updating the plugin.

  1. Install or update Acode.
  2. Download the Agent Console plugin ZIP.
  3. In Acode, open Plugins → + → Local and select that ZIP. Update the existing Agent Console plugin if prompted.
  4. Return to Agent Console, open a text file, and tap Edit.

Loading plugin download…

Edit opens the file and its remote project tree. Tap folders to browse and files to edit. Save in Acode to update the workspace file. If another tool changes the file, saving stops with a conflict and keeps your edits open.

Save before closing Acode. Bridge tabs are not restored after an app restart.
