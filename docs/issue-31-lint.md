# Lint and format rollout (Refs #31)

## Boundaries and data flow

`npm run lint` checks this checkout; `npm run lint:fix` applies safe fixes and formatting. Both call `sh tooling/repos/lint [--fix] PATH...`. Without paths the runner checks only agent-console, brain, portfolio-lab, quant-harness, and dotfiles under `~/repos`; it never discovers sibling worktrees by glob.

The runner validates every target directory and that `biome` and `ruff` are on `PATH` before `--fix` can change a file. Each target runs in its own subshell. Biome checks JavaScript, TypeScript, CSS, HTML, and JSON; Ruff checks and formats Python. The exit status is non-zero when any tool fails on any target, so a Ruff lint error is not hidden by a later successful format check. Unknown options and missing directories fail before any tool runs.

The configs live in `tooling/repos/`. The root `biome.json` and `ruff.toml` extend them, and the runner passes them explicitly, so a private checkout does not depend on files in its parent directory. Locally Biome runs through `rtk proxy biome` when RTK is installed, because the RTK hook mangles Biome output. CI installs Biome 2.5.15 and Ruff 0.17.1 and runs `npm run lint` before the tests.

Excluded from both tools: `node_modules`, virtual environments, `.git`, `.codegraph`, `vendor`, `.impeccable`, `test/tmp`, agent scratch directories, minified JavaScript, lockfiles, SVGs, generated documentation HTML and JSON, and the generated `arch-evidence/` PR artifacts. Ruff also excludes Markdown so fenced examples stay untouched.

## Commits

1. Tooling: runner, configs, `test/repos-lint.ts`, npm scripts, CI step, and `AGENTS.md`.
2. Formatting only: `biome format --write` and `ruff format`. Python ASTs are identical before and after.
3. Safe fixes: `biome check --write` and `ruff check --fix` (import organization, `node:` protocol, `const`, pyupgrade).
4. Hand fixes for the remaining errors.

## Rule decisions

- Biome `noControlCharactersInRegex` is off. ANSI stripping and filename sanitizers match control characters on purpose; removing those ranges would weaken sanitization.
- Biome `noAssignInExpressions` is off. Regex iteration loops (`while ((m = re.exec(s)))`) and cache initialization assign inside expressions on purpose; rewriting them only for lint adds behavior risk.
- Ruff `E501` is off. Ruff format already wraps code at 100 columns; embedded JavaScript, exact test strings, URLs, and prose cannot be split without changing their values.
- All other recommended rules stay on. Existing `any`, non-null assertion, CSS specificity, and style diagnostics remain visible as warnings and infos. HTML suppressions name the runtime behavior that static analysis cannot see.

## Regression check

`test/repos-lint.ts` failed first against the old `~/repos/lint`: an explicit clean checkout failed because that runner ignored its argument and scanned all of `~/repos`. The test now runs real Biome and Ruff against a checkout whose path contains a space and `$`, and checks failure aggregation, safe fixes, untouched vendored and generated bytes, the default five-repository scope, missing targets, and unknown options.

## Other repositories

This change covers agent-console only. brain, portfolio-lab, quant-harness, and dotfiles are separate checkouts and need their own per-repository worktree and commits. After this merges, `brain/config/repos/` should adopt `tooling/repos/` so `~/repos/lint` gains the explicit-path and exit-status fixes. Until then, do not use the old `~/repos/lint --fix` on a private checkout.
